## Install on your device

### iPhone & iPad
1. Open the link above in **Safari** (not Chrome).
2. Wait until the unlock screen appears.
3. Tap **Share** (square with upward arrow).
4. Tap **Add to Home Screen**.
5. Confirm — you should see the **SU Needles** icon.

### Android
1. Open the link above in **Chrome**.
2. Wait until the unlock screen appears.
3. Tap the **⋮** menu (top right).
4. Tap **Install app** or **Add to Home screen**.
5. Confirm — you should see the **SU Needles** icon.

> Tip: Install from the browser page (https://…), not from the Downloads folder. Adding from Files only creates a generic HTML shortcut.

### Windows PC
1. Open the link in **Google Chrome** or **Microsoft Edge**.
2. Wait until the unlock screen appears.
3. Look for the **install icon** in the address bar, **or** open the browser menu → **Install SU Needle Matcher** / **Apps** → install.
4. The app opens in its own window and can be pinned to the taskbar or Start menu.

After install, the first load should be online so the app can cache. It can then be used offline from the Home Screen / desktop icon.

## SU Needle Matcher

### Classic car carburettor tooling

**Find the closest matching needle — or a richer or weaker alternative — by comparing a measured or desired profile against the official tables.**

Built for owners, tuners and restorers who want clear, practical answers — not guesswork.

### What it does
- **Closest profile match** — ranks needles by shape (RMS)
- **Richer & leaner suggestions** — progressive alternatives with annular-fuel context
- **Direct compare** — overlay any needle for a side-by-side check
- **Clear graphs** — diameter and fuel %; each line ends at that needle’s last real data point
- **Home-screen app** — install on phone, tablet or PC with the SU Needles icon
- **Works offline** — after the first online visit

### Designed for real workshop use
Select the correct jet family, enter or load a profile, and get ranked matches with readable metrics and graphs. Variable-length station data is handled cleanly so short and long needles compare honestly.
