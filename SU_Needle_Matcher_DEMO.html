What this tool does

Compare a measured or desired SU carburettor needle profile against the official tables. Ranks by shape (RMS) and annular fuel capacity. Use Direct compare to overlay any needle even if it is not in the top list.

About this Demo

This is a marketing preview with a fixed set of 5 sample needles (MOW, GG, EB, AA, GL) from the 0.090″ Fixed family. Layout and workflow match the full application. The complete product includes all official tables, full matching engine, variable-length handling and author tools.

How to use the demo

1. Load a sample needle or type station diameters
2. Tap Find matches
3. Review closest match, richer/leaner suggestions and graphs
4. Use Direct compare or tick needles to overlay on the charts
